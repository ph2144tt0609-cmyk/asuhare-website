# asuhare-website ─ あすはれ薬局 ホームページ

あすはれ薬局（静岡県三島市谷田夏梅木596-1／運営 株式会社テトテリンクス）の公式サイト。

- **公開URL： https://tetote-links.co.jp/**（www ありへの切り替えは未完了。`DEPLOY.md` の「残っている作業」）
- 配信＝**GitHub Pages**（`main` ブランチ直下をそのまま配信・`CNAME` がカスタムドメイン）

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | ホームページ本体（1ページ完結）。文章・営業時間・電話番号はここ |
| `assets/style.css` | 見た目（色・余白・文字の大きさ） |
| `images/asuhare-exterior.jpeg` | 外観写真 |
| `CNAME` | GitHub Pages のカスタムドメイン指定。**消さない・書き換えない** |
| `.nojekyll` | GitHub Pages に Jekyll を通させないための空ファイル。**消さない**（消すと `_` で始まるファイルが黙って配信されなくなる） |
| `robots.txt` / `sitemap.xml` | 検索エンジン向け。URLを変えたらここも直す |
| `公開.bat` / `publish.ps1` | **ダブルクリックで公開**（変更ファイルを表示→確認→コミット→push→1〜2分で反映） |
| `DEPLOY.md` | 公開・更新・独自ドメインの手順書 |

**JavaScript は `index.html` 末尾の数行だけ**（スマホメニューを項目選択で閉じる処理）。`.js` ファイルは無い。
元サイト（ChatGPTのサイト公開機能で作られた React 製）の 270KB の JS はハイドレーション用で表示に関与していなかったため全て外してある。戻す必要は無い。

## 直し方

1. このフォルダで Claude Code を開き、日本語で頼む（例「営業時間に祝日の行を足して」）
2. `index.html` をブラウザにドラッグして見た目を確認
3. **`公開.bat` をダブルクリック** → 変更ファイルの一覧を確認して `y` → 1〜2分で本番に反映される
   （main 以外のブランチ・`CNAME` が無い・公開してはいけない種類のファイルがある、のどれかなら止まる）

詳しい手順・独自ドメインの設定・残作業は `DEPLOY.md` を見る。
